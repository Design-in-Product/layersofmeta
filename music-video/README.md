Audio assets for the "Saint Lucifer" music-video project, shared here for the
coworker agent. Stored as plain git blobs (not Git LFS) so they're directly
readable in a sandboxed environment.

| File | What it is | Size |
|------|------------|------|
| `saint-lucifer.mp3` | Full song reference mix | 6.5 MB |
